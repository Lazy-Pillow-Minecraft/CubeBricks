# 功能概览 / Features

[English](FEATURES.en.md) · [返回 README](../README.md) · [操作教程](USER_GUIDE.md) · [文件格式与恢复](FORMATS_AND_RECOVERY.md)

CubeBricks 仍在原型开发阶段。以下列出当前的主要工作流与边界，而不是更新日志；尚未完成的功能会明确标示。

## 建模与场景

- 以 Cube 为基础几何，支持组、Locator、节点、二维／三维 Bezier 曲线，以及多边形柱体、正十二面体、足球形截角二十面体等程序化 Shape。Shape 可保留参数，并单独记录对生成 Cube 的细分修改。
- 场景层级支持多选、范围选择、搜索、分组、拖动排序与快速定位。可见性、锁定、自动 UV、UV 归一化及导出标记可在详细列表管理。
- 移动、缩放、旋转、枢轴移动、顶点捕捉、交点显示、刀具与面选择分别处理几何交互。移动和旋转可选自身、父级或全局参考；枢轴移动会补偿几何位置。
- UV 编辑默认并入编辑模式，也可开启独立模式；Blockbench 风格视角操作可选，支持左拖旋转、右拖平移及 Shift 左拖框选。
- 组与元素可各自挂载修改器；内置对称支持 XYZ、径向与曼陀罗，可重复挂载、预览和逐个烘焙。程序化结果在 `.bbmodel` 导出时展开为兼容的 Cube／组。
- 即时操作器与修改器分开；当前的绘画对称操作器关联可匹配的面及其 UV 边长，不生成额外场景元素。

## 视图与工作区

- 提供透视、正交和独立的六向轴视图；轴视图仅正交，摄像机可平移、环绕、缩放及缓动聚焦。
- 线框、体块、纹理和法向显示模式可切换。网格、手柄、线框与模型表面各有适合自身的渲染处理。
- 主视图支持参考图、玩家视觉参考、模型透明背景截图，以及锁定对象和修改器结果的独立虚化显示。
- 多项目页签和左、右、底部可停靠面板可拆出、吸附、合并为多页签部件、折叠与调整尺寸。

## UV、贴图与图层

- Cube 可使用逐面或箱型 UV；逐面模式下各面可独立选贴图、旋转、镜像、剔除及编辑 UV。贴图模式下拉菜单目前只允许选择普通贴图；平铺和手翻书显示为不可点击的「即将推出」选项，已有数据仍可读取。
- 图层支持图片层与组、排序、可见性、透明度、混合模式、色阶映射及独立蒙版来源。图层编辑子窗口可查看完整贴图和选中图层。
- 新建贴图可选纹理模板、纯色模板或空白贴图。模板按工程基础吸附分辨率分配 UV，非零边至少 1px，可清理零面积面、选择箱型 UV、留间隔并按 2 幂或指定倍数裁切画布。
- 纹理模板的「保留图层结构」默认开启：按新 UV 重排各来源图层像素，保留组、顺序、可见性、混合设置及遮罩关联；多来源贴图会分别成组。关闭时沿用合成单张贴图的流程。箱型 UV 在允许逐面 UV 的格式中默认关闭；格式强制箱型时仍遵循格式限制。
- 左侧贴图视图可多选面、移动和拉伸 UV；UV 预览显示选中内容、面向区分、旋转与镜像标记。

## 绘画与色彩

- 在二维贴图或三维模型面上绘画，包含画笔、图形绘制、油漆桶、渐变及取色器。画笔支持方形／圆形笔尖、AA、透明度、跨面连续笔画与笔刷深度；未分配贴图的面不会自动取得贴图。
- 绘画选区可使用矩形、涂抹或自由圈选；Shift 追加、Ctrl 擦除。选区可限制绘画，并在二维贴图内移动、复制或旋转像素。
- 色卡支持离散色、渐变及三维色彩空间曲线，并可单张导入／导出 `.cbcmap`。选色器提供方形、圆形与三角形 HSV 界面。
- 绘画模式的场景层级保留查找、选取、聚焦与可见／锁定切换，但不修改模型几何；几何编辑须回到编辑模式。

## 工程与扩展

- `.cbmodel` 保存模型、贴图和操作历史；`.bbmodel` 用于 Blockbench 交换。工作目录保存可恢复的操作日志，导出可选择是否包含历史。
- 模型格式由注册表定义。Java 方块／物品有三种版本旋转规则、强制背面剔除和元素坐标范围；基岩版方块有动态 30px 尺寸约束。两者都在视图中显示完整的范围参考线框。模组版实体限制为箱型 UV、整数 Cube 尺寸及组旋转。
- Minecraft 皮肤与 GeckoLib 格式暂时禁止新建；已有项目与导入识别保留。
- Java 方块／物品不提供动画模式，显示设置页目前仅为占位。其他格式的动画编辑也显示占位提示，完整动画工作流尚未实现。
- 外部 [Shape 包](../SHAPE_PACKS.md)、[语言／字体包](../RESOURCE_PACKS.md) 可从资源包管理器加载；尚未开放外部修改器或操作器包。
