# CubeBricks 0.1.4-beta

[English](RELEASE_0.1.4-beta.en.md) · [返回 README](../README.md) · [上一版说明](RELEASE_0.1.3-beta.md)

## 本版改进

- **平铺与 UV：** 普通 UV 改用起点和宽高显示；平铺独立保存面的偏移、整体像素宽高，支持接缝绘画。模式栏保持固定，UV 预览聚焦可自动切换贴图。
- **手翻书：** 图层管理增加独立帧列表与多对多曲线关联、逐帧显隐和绘画目标记忆。各贴图独立播放，可拖动进度与点击帧刻线，支持帧渐变及同目录 `.png.mcmeta` 导入。
- **导出烘焙：** `.bbmodel` 自动烘焙平铺和动画；单贴图格式合并所有贴图，以动画帧数最小公倍数循环、平均 FPS 播放，关闭帧渐变。多贴图格式分别保留；平铺尽量重叠引用，箱型专用格式保留固定六面展开。编辑工程不受影响。
- **项目与历史：** 首页独立页签、保存项目持久化标记、已有项目确认删除、大项目打开与后台历史读取进度。历史窗口支持圆盘分支图、节点标记、聚焦和单节点／分支删除，历史上限从最早记录逐条清理。
- **贴图稳定性：** 修复多贴图与复制纹理之间的像素串用，改进图层缩略图的实时更新，并固定图层编辑窗关闭后进度条的位置。

## 上传备注

源码与模块依赖检查、模型与渲染检查、79 项历史／撤销检查通过；安装包内程序的隔离启动及 38 项导出像素／参数检查通过。

CubeBricks 0.1.4-beta 完善平铺与手翻书贴图工作流，加入帧与图层关联、独立播放、逐帧显隐和动画配置导入。bbmodel 导出可烘焙全部动画，按格式自动合并单贴图图集，平铺区域尽量重叠复用。新增项目持久化管理和可标记的圆盘历史视图，改善多贴图切换、复制及实时缩略图更新。同步更新简中与英文文档。
