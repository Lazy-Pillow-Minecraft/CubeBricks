# CubeBricks 0.2.3-beta 更新日志

[English](RELEASE_0.2.3-beta.en.md) · [返回 README](../README.md)

发布日期：2026-11-21。安装包：`CubeBricks-v0.2.3-beta-win-x64-setup.exe`。

本日志以 **0.2.2-beta 原版**为起点，汇总其后的热修、日期码版本和本次动画编辑更新。已经安装中间热修版的用户会看到部分熟悉的改动。

## 动画编辑

- 开放支持动画的模型格式的动画模式，新增动画管理、帧属性和底部关键帧停靠卡片。动画管理可创建、命名、删除动画，调整编辑帧率、结束帧与循环类型。
- 动画模式只选择组：点击模型会选择所属的最下层组，Shift 点击继续向上寻找父组。场景层级只显示组；包含 Locator 的组附加较暗的 Locator 标识，末级组不显示多余的折线和折叠按钮。
- 工具栏保留移动、缩放、旋转、枢轴和工具箱。移动、旋转、缩放写入当前动画关键帧；缩放作用于整组矩阵。枢轴仍直接修改模型，其他动画变换不改写基础几何。
- 手柄产生非零变化时即时写入关键帧，整次拖动归为一步撤销。未配置的通道显示 `-`；编辑器创建的轨道首次在后续时间写入关键帧时，会补充默认起始帧，已有起始帧保持原样。
- 手柄保持正常尺寸与朝向，不随模型矩阵拉伸或剪切。修正旋转松手后姿态变化、累计圈数丢失以及有初始旋转的骨骼与基岩动画叠加规则不一致的问题。

## 关键帧时间轴

- 左侧组名平级排列并固定，右侧使用棋盘格背景和每行一根中轴线；仅顶部标尺显示刻度。组名分隔线延伸至底部，0 帧前保留一段不可用留白。
- 时间轴可继续向结束帧后滚动；Ctrl＋滚轮调整密度，主刻度和弱刻度随缩放调整，修正大倍率下的多余线条。
- 播放指示线改为顶部倒三角与主题色细线。拖动时按 Ctrl 取消整帧吸附。
- 关键帧可在所属行内拖动，定位只看鼠标横坐标；靠近左右边缘自动滚动。松手落在结束帧后会延长动画，按 Shift 松手则限制在原结束帧内。
- 右键按下或拖动顶部标尺直接设置结束帧，不弹菜单；结束位置用主题色 `]` 标记，其后的标尺变暗，且不能早于最后一个关键帧。
- 关键帧选择与播放位置解耦，支持多选；多选不显示帧属性。只有指向实际关键帧时才显示拖动光标。
- 新增三种循环类型：不循环并回到开头、停止于最后一帧、循环。修正播放周期多算一帧的问题；保留小数时间，调整编辑帧率保持实际秒数不变。

## 动画文件与渲染

- 动画管理栏新增导入／导出；主导出窗口也提供基岩版动画 `.animation.json`。文件附加到当前模型，按模型实际导出的骨骼名绑定，可导出当前动画或全部动画。
- 支持数字位移、旋转、缩放、标量缩放、`pre/post` 及线性、Catmull-Rom 插值。保留未修改的原始时间键、表达式、扩展字段及未匹配骨骼的数据；编辑后的骨骼名与模型导出命名共用规则。
- `.bbmodel` 导入导出增加骨骼动画，`.cbmodel` 和工作历史保存动画及其原始附加数据。
- 动画预览按组缓存网格，播放时更新矩阵；后台分批准备动画网格，保留编辑模式缓存，减少切换时的重复构建。
- **当前边界：**Molang、声音／粒子事件、实体相对旋转等动态内容会保留，但尚不完整执行预览；动画控制器与游戏内挂接尚未实现。不能表达的插值会明确提示，不会静默替换。

## 建模、工具箱与组

- 新增工具箱，位于面选择之后，内部切换等比缩放、翻转、90°旋转和居中。
- 等比缩放支持包络框尺寸吸附、每个元素分别吸附及不吸附；长宽高分别吸附，支持拖动中切换 Shift、Ctrl、Ctrl＋Shift 精度。
- 翻转支持全局原点和枢轴中心，共六个轴向按钮；90°旋转支持两种中心、三轴正负方向，共 12 个按钮。居中可按几何中心或枢轴进行单轴、整体操作。
- 追加 X、Y、Z、YZ、XZ、XY 和全局旋转补偿，计入父组朝向；轴向按钮使用红绿蓝区分。
- 翻转可同步交换 `left/right`、`up/down`、`front/before` 方向片段，保留大小写风格，避免误改普通单词；组名冲突自动去重。工具栏可关闭换名，对称修改器可选择是否先清理旧方向词。
- 组右键新增「分组元素」，单个元素也能就地包组。G 创建空组，Shift＋G 为选中项分组。
- 组右键新增「解析组」：主项直接点击等同正常解析，下级菜单另提供不补偿旋转的方式。仅拆当前层，保留子组、原位置顺序及相关 UV、膨胀、显隐、锁定信息。
- 刀具只由起点确定切割对象，终点决定方向，不再要求同面或同一元素。
- 修改器虚拟结果可以选中并映射编辑源元素，手柄跟随生成实例；选框改为色相翻转，保留明度和饱和度。
- 修改器／操作器改用六点手柄排序，拖拽时显示折叠标题条，支持滚轮及边缘滚动，松手后统一提交。

## 格式、UV 与绘画

- Java 方块／物品新增取消区域限制选项；导入坐标越界的 bbmodel 时自动关闭区域限制，并保留相应格式设置。
- 修正受限 Java Cube 的 90°旋转折算，保留原斜角、负尺寸和隐藏面；修正姿态换算、膨胀与程序化内容烘焙时的偏差。
- 修正元素拷贝节点的同层坐标：节点不随源元素自身变换移动，但会跟随祖先组；修正相关烘焙／导出坐标转换。
- 贴图右键新增调整尺寸窗口，提供直接裁切、重复、拉伸；拉伸同步更新已分配 UV，并吸附实际像素格点，支持图层与撤销。
- 图层可生成具有最小间隔的均匀随机圆点，设置尺寸和间隔；可按绘画对称关系只生成一份并复制至对应面。
- Shift＋滚轮调整笔刷／图形尺寸，二维和三维视图均可使用；Alt 取色及色卡滚动保留优先级。
- Alt 支持双向缩放；起手为负尺寸的轴会反转缩放手柄方向，拖动中不突然翻转。
- 修正取色器随停靠宽度布局和三角环定位；修复默认色卡拖动不生效，渐变节点圆环与竖线改用主题色并消除间隙。
- 修复「忽略全透明」报错；透明命中缓存保留单笔开始时状态，避免擦除时连续穿透。按变更区域更新贴图快照，减少大贴图的小面积操作开销。
- 改进连续绘画提交顺序、失败处理和日志重试，避免后续操作悄悄越过失败记录；重试同一提交不会重复创建历史步骤。
- 历史窗口遇到非当前节点损坏时保留损坏标记，继续展示可读取记录；跳转仍校验目标数据。

## 工作区与外观

- 新增紫色、黑白配色及六套低边框色块版，共 12 个主题；各自支持明亮、深色和跟随系统，移除五个零散颜色覆盖项，修正重启后的主题持久化。
- 数字框统一使用左右步进按钮、横向拖动及悬浮滚轮，按字段用途适配吸附；保留文本输入和 Shift／Ctrl 精度。主视图变换提示只显示当前手柄的有符号变化量。
- 停靠卡片排布、尺寸、折叠、合并分页和选中项独立持久化，修复重启恢复时被旧布局覆盖的问题。
- 新增每模式独立的左右下角遮挡关系开关，可选择侧栏或底栏延伸至窗口边缘；编辑／绘画默认侧栏优先，动画默认底栏优先。
- 动画模式默认左侧动画管理／帧属性、右侧场景层级、底部时间轴；移除 UV 预览和对象属性。绘画／动画模式的层级搜索与数量合并为一行。
- 改进元素／图层组的投放区域、末端吸附、缩进遮挡及节点折线，完善拷贝节点刷新和独立折叠。
- 参考图柔光改为固定屏幕宽度，新增锁定保护，保留取色能力。
- 快捷键支持鼠标侧键，编辑绑定时 Esc 清空该项；界面缩放下限降至 50%。新建 Cube 使用创建时的主题色。
- 修正桌面进程名称和图标、开发版启动问题，统一多处菜单图标、按钮与下拉框样式，补充标准翻译键。

## 简短上传备注

0.2.3-beta：开放组动画与关键帧时间轴，支持三种循环方式及基岩动画 JSON 导入导出；合并 0.2.2 以来的工具箱、旋转补偿、分组／解析组、贴图尺寸调整、随机点、主题与数值框改进，并修复停靠持久化、UV／烘焙、连续绘画及历史记录相关问题。动画动态脚本、事件预览和控制器仍在完善。
