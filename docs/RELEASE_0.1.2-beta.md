# CubeBricks 0.1.2-beta

[English](RELEASE_0.1.2-beta.en.md) · [返回 README](../README.md)

## 相较 0.1.1 的改进

- **变换编辑：** Cube、组和 Shape 可分别应用位移、旋转，将属性栏的对应数值归零；还原可取回数值，模型外观不变。组新增独立位置栏，导出仍写入最终姿态。
- **曲线和对称：** 包络曲线的嵌套烘焙及导出保留组层级，组的枢轴与朝向跟随最外层 Cube 的起始面；对称烘焙保留重合组的层级，单个 Cube 的结果仍为 Cube。
- **旋转操作：** 改善旋转手柄跨越 180° 时的连续性，并修正 Java 单轴角度限制和组旋转的拖动方向。
- **撤销与截图：** 修复撤销后曲线节点选择错位及局部手柄异常；模型截图会刷新当前几何，预览中可临时开启自动裁剪并查看裁剪框。
- **启动与视图：** 首屏加载时用纯背景遮住尚未完成的界面；首次在使用中键前以左／右键拖动建模视图，会提示可在设置中选择 Blockbench 风格操作。中键拖动时可实时切换 Shift 的环绕／平移模式。
- **界面与格式：** 调整绘画模式右键菜单及枢轴居中按钮位置；暂停新建皮肤和 GeckoLib 模型的入口，同时保留已有项目识别。补齐简体中文与英文界面文本。

## 上传备注

CubeBricks 0.1.2-beta 重点改善变换、烘焙与稳定性：Cube／组／Shape 可应用或还原位移与旋转；包络曲线和对称烘焙更准确地保留层级；旋转拖拽可连续越过 180°；修复撤销后节点手柄异常和截图未及时更新，并为截图加入可选自动裁剪。首屏加载、操作提示及多语言文本也一并整理。

Windows 安装包：`CubeBricks-v0.1.2-beta-win-x64-setup.exe`。
