# CubeBricks 0.2.2-beta-hotfix-20261120 更新内容

对照起点为 **0.2.2 热修**。核对使用本地保留的 `0.2.2-beta-hotfix-20261118` 安装包内实际源码，合并其后的日期码构建和本次新增，不重复列出该起点已经具备的功能。

安装包：`CubeBricks-v0.2.2-beta-hotfix-20261120-win-x64-setup.exe`。

## 建模工具与组

- 新增「工具箱」，位于面选择之后，通过内部下拉框切换等比缩放、翻转、旋转、居中四类工具。
- 等比缩放使用中央方块手柄，向上放大、向下缩小；支持整体包络框尺寸吸附、各元素尺寸分别吸附和不吸附。吸附时长、宽、高分别取格点，支持拖动中即时切换 Shift、Ctrl、Ctrl+Shift 精度。
- 翻转提供全局原点和枢轴中心两组 XYZ 按钮；旋转提供两种中心下 XYZ 正负 90°，共 12 个按钮；居中可按几何中心或枢轴执行单轴、三轴操作。
- 旋转类别追加七个旋转补偿按钮，顺序为 X、Y、Z、YZ、XZ、XY、全局。补偿计入父组累计朝向，各选中对象围绕自己的枢轴调整；全局补偿对齐世界坐标系。YZ、XZ、XY 分别使用 X、Y、Z 轴颜色。
- 组右键新增「解析组」下级菜单。直接点击主项或选择「正常解析」会保持内容物的场景位置与朝向；「不补偿旋转」直接解除该层级、保留子项原有局部变换数值。子组保持完整，直接子项按原顺序替换当前组，整次操作支持一步撤销。
- 解析组时保留子项 UV、继承的膨胀、显隐和锁定状态，并处理子项自身修改器／操作器坐标、已应用变换及受限格式所需的旋转组。
- 刀具第二次点击仅决定切割方向，可落在其他面、其他元素或背景上；不再要求与起点同面，正交和透视采用一致的平面计算。
- 修正整体翻转后程序化 Shape、曲线节点和手柄、细分 Cube 及 UV 覆写的坐标换算；变换继续保留组层级和 Shape 参数。

## 方向命名与修改器

- 翻转可同步交换对应轴的 `left/right`、`up/down`、`front/before`，忽略匹配时的大小写并保留原有大小写风格。按独立词、分隔符、数字和驼峰片段识别，避免误改 `group`、`backup` 等普通名称。
- 翻转后的组名按项目内序列补空号去重，自动命名子项跟随最终组名；换名与几何变换共同撤销。工具栏可关闭同步换名，偏好会保存。
- XYZ 对称修改器新增默认开启的「清理已有方向词」：烘焙、导出前先清理旧方向片段，再添加本次方向前缀；关闭后直接在原名上追加。子组和独立 Cube 同样生效，径向、曼陀罗编号不变。
- 修改器生成的虚拟元素可直接选中，并映射编辑源元素；移动、旋转、缩放与枢轴手柄跟随选中的生成实例，支持对应实例的顶点捕捉。右键保留已有多选并提供源元素菜单。
- 生成部分的选中框改为原选框颜色的色相旋转 180°，保留饱和度与明度；黑白、灰色保持原样。
- 修改器与操作器移除上下箭头，统一用左侧六点 `⠿` 手柄拖动排序。手中的卡片仅显示不透明的折叠标题条，实际展开状态不变。
- 排序按鼠标 Y 坐标定位，超出列表吸附首尾；支持滚轮和边缘自动滚动。拖动预览不改变执行顺序、不重建模型，松手后统一提交一步撤销。
- 操作器后台关联完成时不会打断正在进行的卡片拖动；拖动中滚轮经过数值框会滚动列表，不会误改属性。取消、失焦、切换项目会清理拖拽状态。

## Java 格式与 UV

- Java 方块／物品项目新增「取消区域限制」，可在新建和项目信息中调整。导入原始坐标超出范围的 bbmodel 时自动关闭区域限制，并保留旋转版本与 UV 规则。
- 区域限制设置随 cbmodel、bbmodel 保存和重新导入，原生 JSON 导出也遵循该选项。
- 修正受限 Java Cube 的 90°旋转：把完整直角部分折算为尺寸及面 UV 变换，必要时调整剩余旋转轴，保留原斜角、负尺寸和剔除面。
- 修正姿态换算及组膨胀叠加时出现的额外尺寸变化，统一预览、编辑与烘焙的处理。
- 贴图尺寸使用「拉伸」时同步拉伸已分配 UV，并吸附到实际像素格点；兼容箱型 UV、高分辨率贴图和 Shape 细分覆写，像素与 UV 一同撤销、重做。

## 绘画与色卡

- 新增 Shift＋滚轮调整画笔／图形工具尺寸：向上增大、向下减小，二维贴图与三维模型视图均可使用；支持触控板累积、小工具各自尺寸及快捷键重设，Alt 取色／色卡滚动保留优先级。
- 修复「忽略全透明」触发 `Cannot read properties of undefined (reading 'get')` 的问题，统一命中检测和绘制使用的透明缓存。
- 保留单笔开始时的透明状态，避免擦除过程中意外连续擦穿多层；下一笔再识别新的透明区域。透明检测按需要读取缓存块，减少整张贴图读取，笔画完成后释放缓存。
- 修复默认色卡拖动后排序不生效的问题。
- 渐变色值节点的圆环和竖线统一使用主题色，并补齐两者之间的间隙；当前取色位置指示保持原有样式。移除多余的色卡统计提示。

## 参考图与工作区

- 参考图编辑边缘的主题色柔光改为固定屏幕宽度，不随图片分辨率、图片缩放或正负轴视图缩放改变。
- 参考图菜单新增锁定开关，复用已有锁定图标。锁定保护当前项目的全部参考图，阻止误入编辑、拖动及缩放；导入图片也不会自动进入调整状态。取色仍可使用，锁定随项目保存并支持撤销。
- 修复停靠卡片布局重启后丢失、恢复时排序被覆盖的问题，独立保存左右停靠、浮动位置、尺寸、折叠、合并分页及选中项，并在关闭前完成写入。
- 保留旧布局迁移和桌面／浏览器存储回退，避免启动时的较旧读取覆盖用户刚调整的布局。

## 主题、图标与界面

- 新建 Cube 在创建时使用当前主题色，并保存为该元素的显示颜色；切换主题不会覆盖已有元素颜色。
- 界面缩放下限由 85% 降至 50%。
- 统一新建菜单与场景层级的元素图标，更新工具箱、翻转、90°旋转、居中及旋转补偿 SVG；外部 Shape 无自带图标时使用统一 Shape 图标。
- 工具箱轴向按钮用红、绿、蓝区分 XYZ；UV 预览翻转按钮保持普通主题样式，旋转和翻转共用更新后的 SVG，移除多余的 90°文本。
- 提亮工具箱及 UV 预览按钮，枢轴居中按钮改为正方形，修复工具箱下拉菜单开头的多余方块。
- 统一拷贝节点「新增节点／删除节点」按钮的字号、背景、边框、尺寸和悬停状态。
- 移除主视图背景、元素右键菜单的前置装饰图标，补齐新增功能的标准翻译键和中英文操作说明。
