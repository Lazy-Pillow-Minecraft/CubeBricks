# 操作教程 / User Guide

[返回 README](../README.md) · [啟動與建置](GETTING_STARTED.md) · [功能概覽](FEATURES.md)

## 1. 建立、保存與切換項目

1. 從首頁的模型類型列表或頂部「新建」選擇項目格式。格式會給出初始吸附與 UV 能力；Java 方塊／物品的版本限制可在項目信息中調整。
2. 頂部頁籤可切換和拖動排序；右鍵頁籤編輯項目信息，中鍵或懸浮時的叉號關閉。
3. `Ctrl+S` 保存，`Ctrl+Shift+S` 另存；導出時依所選或輸入的副檔名決定 `.cbmodel` 或 `.bbmodel`。
4. 關閉桌面版時，只會詢問本次啟動新建的項目是否保留；取消勾選才會刪除其展開式工作目錄。已存在並重新打開的項目不在此刪除列表內。

## 2. 攝像機與選取

| 操作 | 結果 |
| --- | --- |
| 中鍵拖動 | 一般視圖環繞；軸向視圖平移 |
| `Shift` + 中鍵拖動 | 平移一般視圖 |
| 滾輪 | 縮放主視圖 |
| `R` / `Shift+R` | 聚焦選中內容 / 回到場景中心；貼圖視圖獲得焦點時改為貼圖內聚焦 |
| 點擊六向輪盤 | 進入相應正交軸視圖；再次點同方向可翻到對面 |
| 拖動輪盤 | 退出軸視圖，回到一般視圖 |
| 左鍵模型 / 空白處 | 單選 / 清空選取 |
| 左鍵拖框 | 框選；`Shift` 追加，`Ctrl` 從現有選取移除 |
| `Ctrl+A` | 在主視圖或場景層級全選可用元素 |

場景層級與主視圖共用物件選取。列表可以多選、搜索、拖動排序與拖入組；拖動途中可滾輪捲動或靠近列表邊緣自動捲動。右鍵物件或列表項可使用相同的物件操作選單。

## 3. 建模與變換

場景層級上方可新增 Cube、組、Locator 和 Shape。新 Cube 是底部落在水平面上的 2×2×2 立方體；在組內新增的元素會以組樞軸為初始參考。Shape 建立選單包含柱體、多面體和 Bezier 類型。

| 快捷鍵 | 工具 |
| --- | --- |
| `1` | 移動 |
| `2` | 縮放 |
| `3` | 旋轉 |
| `4` | 移動樞軸 |
| `5` | 頂點捕捉 |
| `6` | 刀具 |
| `7` | 面選擇 |

- 手柄只接受左鍵；中鍵保留給攝像機。軸、平面和中心手柄分別執行相應維度的操作。
- 移動與旋轉可選自身、父級或全局坐標；多選可在統一與分別執行間切換。樞軸移動會補償物件參數，不改變可見幾何。
- 旋轉時按住 `Alt` 可暫時顯示選中物件頂點；點擊頂點可把樞軸移到該處。頂點捕捉可選交點提示，直角菱形交點只能作目標點。
- `Ctrl+Z` 撤銷、`Ctrl+Shift+Z` 重做；文字輸入框聚焦時，`Ctrl+Z` 優先撤銷文字而非整個項目。
- `Ctrl+C` 複製、`Ctrl+X` 剪切、`Ctrl+V` 貼上、`Ctrl+D` 原位複製。這些操作會依當前焦點作用於可操作的元素或貼圖。

## 4. UV 與紋理模板

1. 在左側貼圖列表建立或導入貼圖，再將列表中的貼圖拖到模型面上。若同時選中多個元素，會對其相同方向的面指派貼圖；換貼圖不會清除原有 UV 或平鋪參數。
2. 在貼圖視圖中選取面與 UV 框。`Shift` 框選追加、`Ctrl` 框選移除；拖動框或邊緣調整 UV。貼圖視圖的 `Ctrl` + 滾輪縮放，普通滾輪縱向捲動，`Shift` + 滾輪橫向捲動，中鍵拖動平移。
3. 貼圖視圖聚焦時，`R` 聚焦選中 UV，`Shift+R` 還原貼圖視圖。UV 可以保留在貼圖範圍外以兼容特殊資料，但普通拖動不會主動把它推出去。
4. 「新建貼圖 → 紋理模板」會依當前 Cube 面重新排布 UV。可選僅處理選中項、清理零面積面、箱型 UV、尺寸對齊、間隔與保留多紋理佔位。
5. 「保留圖層結構」預設開啟：每張來源貼圖的各圖層會依新 UV 分別重排，組、可見性、混合模式與遮罩關聯保留。多來源貼圖各成一組；未貼圖的面放在模板底圖。關閉此選項則輸出單張合成圖。箱型 UV 預設關閉，只有格式要求箱型時強制使用。

## 5. 繪畫

在頂部切到「繪畫」。畫筆、圖形繪製、油漆桶、漸變、取色器與選區位於繪畫工具欄；圖形工具和選區工具可在工具內切換子模式。常用快捷鍵：`B` 畫筆、`L` 直線、`M` 矩形、`O` 橢圓、`G` 油漆桶、`J` 漸變、`I` 取色器。按住 `Alt` 可臨時取色，鬆開返回原工具；當前顏色對應選中色卡時，也可按住 `Alt` 滾輪切換色卡顏色或漸變位置。

- 二維貼圖與三維模型面都可繪畫。畫筆可以從三維空白處起筆、跨面連續落色；未指定貼圖的面不會被自動綁定當前貼圖，需先指派。
- 畫筆可選尺寸、方形／圓形筆尖、AA、透明度和筆刷深度。圖形繪製可選填充，油漆桶可沿一次拖動處理多個面或位置。
- 面漸變與體漸變以兩點決定方向，覆蓋完整目標；可用兩個色槽或目前色卡。色卡可使用離散色、連續漸變或三維色彩空間曲線。
- 選區有矩形、塗抹、自由圈選。`Shift` 追加，`Ctrl` 擦除；繪畫只作用於選區。貼圖視圖中的像素變換可移動、複製或旋轉選中像素。
- 繪畫對稱須先在元素或組的「操作器」頁掛載，再於主視圖編輯對稱軸。它只複製繪畫輸入，不產生新模型。繪畫模式仍可從場景層級切換可見性與鎖定，但不能修改幾何。

## 6. 圖層、色卡和窗口

圖層列表可新增圖片層或組、拖動排序、折疊與切換可見性。列表旁的齒輪打開圖層編輯子窗口，在其中編輯名稱、透明度、混合模式、色階映射和蒙版來源。切換當前圖層不應清空其他圖層；完整貼圖由各層實時合成。

色卡可新增、選色、排序、刪除，並把目前選中的單張色卡導出為 `.cbcmap`；匯入會追加而非覆蓋。色卡列表可縮略顯示。視圖左、右、底部的停靠窗口可拖出、靠近邊緣吸附或拖到另一個窗口的標題上合併；折疊與尺寸在每個停靠位置管理。

## English quick guide

Create a project from the format list, then use the hierarchy to add cubes, groups, locators, and shapes. Middle-drag controls the camera; `R` focuses selection. Edit tools use keys `1`–`7`; `Ctrl+S` saves and `Ctrl+Z` undoes. Assign a texture by dragging it onto a model face. The texture-template dialog can preserve source layer trees while remapping every layer into newly packed UVs (on by default). Switch to Paint for brush, shapes, fill, gradient, eyedropper, and selection tools. The layer gear opens the dedicated layer editor. For details, refer to the Traditional Chinese sections above and the [feature overview](FEATURES.md).
