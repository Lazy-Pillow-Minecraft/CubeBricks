## 1. 建立、保存与切换项目

1. 从首页的模型类型列表选择项目格式。格式会给出初始吸附与 UV 能力；Java 方块／物品的版本限制可在项目信息中调整。
2. 顶部页签可切换和拖动排序；右键项目页签编辑项目信息，中键或悬浮时的叉号关闭。列表末尾的加号新增首页卡片，保留其他项目；在首页新建或打开项目会就地替换这张首页卡片。
3. `Ctrl+S` 或顶部「保存」会保留项目工作资料夹，不生成独立文件。`Ctrl+Shift+S` 或「导出」先打开格式选择子窗口：可选 `.cbmodel`、`.bbmodel`，以及当前格式原生支持的 JSON 或 Java；不支持的选项不提供。
4. 保存状态会写入项目目录，重启后仍有效。保存过的项目在关闭页签或软件时自动保存、不询问，也不会被自动删除。只有新建且从未保存的项目需要选择保留或放弃；取消关闭则继续编辑。
5. 首页项目条目的右键菜单提供「删除项目」，确认后删除该项目的工作文件夹及历史记录，已导出的模型文件不受影响。若该项目仍有打开的页签，也会一并关闭。

打开已有项目超过半秒会显示进度窗。大历史归档先还原当前模型与贴图，其余历史在后台读取；窗口底部的细进度条显示剩余进度，期间可继续编辑及撤销。

从首页选择 **Minecraft 皮肤** 会打开模型选择窗口。顶部切换 Java 版与基岩版；搜索或点击带封面的实体模板，左侧预览会随所选游戏内纹理或六面配色模板切换。未选择模型时，左侧显示空棋盘格。点击「开始绘画」后建立皮肤项目。皮肤项目只提供绘画模式，不提供模型编辑或动画模式。

「导出」右侧的「历史记录」打开圆盘分支窗口。每个末端均分圆周空间；当前节点高亮，末端次高亮，普通节点显示为与连线同色、直径为线宽 2 倍的小点。各分叉点之间以及通向末端的直线段内，节点均匀分布。悬停节点才显示操作与时间提示；滚轮缩放、空白处或中键拖动平移。

左键选中历史节点后，`R` 平滑聚焦该点，`Shift+R` 恢复初始圆盘视图，不改变主视图摄像机或当前模型状态。UV 预览和历史窗口使用同款固定的低对比度棋盘格背景。

节点右键菜单的「标记节点」可选择方形、正菱形、圆形、六边形、五角星或三角形，设置颜色并输入名称；颜色按钮使用现有三种选色器。名称以深色半透明底、亮色文字显示在节点正上方，标记和名称的屏幕尺寸不随图形缩放变化。已标记节点成为当前状态时，图形放大至 1.5 倍并显示固定 3px 白边，名称相应上移以避开图形。再次右键可编辑或移除标记。标记独立保存，不新增历史节点，也不随状态跳转改变；删除或自动清理节点时，其标记一并清理。

右键节点可切换到该历史状态、删除单个节点，或删除节点及后续整个分支。删除需要确认，且至少保留一个状态；当前状态被删除时，先恢复仍保留的父节点或邻近状态。单删不会删除后续记录，失去父节点的分支通过虚线连接共用的虚拟中心，仍可正常切换。

达到历史上限后，按项目全局序号从最早的记录逐个清理，保留较新的各条分支，不会顺带删除整个分支。虚拟中心仅表示较早的连接已被清理，不对应可恢复的模型状态。

项目历史上限在项目信息中设置，留空则使用设置里的默认值。它独立保存，不产生历史节点，也不随撤销、重做或历史跳转改变；调整上限仍会执行必要的旧记录清理。

近期撤销与重做会先从内存恢复画面，再按顺序完成后台存储校验；模型、UV、绘画和图层共用这套缓存。缓存最多保留 8 步，并受内存预算与项目历史上限限制；更早的状态仍从项目历史读取。保存与关闭会等待必要的记录写完。

Java 方块／物品项目会强制背面剔除，只用逐面 UV；其三个版本分别限制为 22.5° 倍数且单轴、任意角度但单轴、以及不限制旋转轴。视图中的范围线框标示元素 `from/to` 可处于的 −16～32 坐标范围；参考地网格向 X/Z 正向偏移 8，红蓝轴仍从原点出发并延长。此格式没有动画模式，「显示设置」目前只是占位页。基岩版方块的范围线框会依当前模型动态移动，提示 30px 尺寸限制；拖动或修改数值若使模型进一步越界，会被拒绝。范围线框使用与地网格主参考线相同的颜色和遮挡方式。

受单轴限制的 Java Cube 会将 90° 整倍数折入位置、尺寸和逐面 UV，再约束剩余角度；面的剔除状态、UV 镜像与负尺寸也会随之保留。导出的 bbmodel 使用顶层 `java_block_version` 保存三档版本，重新导入时恢复对应选项；它与 `meta.format_version` 所表示的 bbmodel 文件版本相互独立。

内置 Shape 和修改器也会遵循格式限制：多边形柱体与曲线在受限 Java 版本中拟合合法角度；对称和拷贝按前序结果约束轴、份数、角度及节点范围。基岩方块的 Shape 整体拟合范围，修改器结果也参与范围检查。模组实体的 Shape 使用整数尺寸与箱型 UV，烘焙和导出时用组旋转保留曲线方向。预览、手动烘焙与导出共用适配；两个球体在 Java 的两种单轴版本中暂不可新建，已有对象保留数据，切换至 1.21.11+ 或其他支持的格式后恢复。

受限 Java 的 Shape 使用旋转柱体逼近原形，保留柱子粗细，不以包围盒或体素填充代替。空间曲线只有在角度误差过大时才增加斜柱段数，使路径连续；没有旋转限制的版本不增加这类分段。

## 2. 摄像机与选取

| 操作 | 结果 |
| --- | --- |
| 中键拖动 | 一般视图环绕；轴向视图平移 |
| `Shift` + 中键拖动 | 平移一般视图；按住中键时可随时按下或松开 `Shift` 切换 |
| 滚轮 | 缩放主视图 |
| `R` / `Shift+R` | 聚焦选中内容 / 回到场景中心；贴图视图获得焦点时改为贴图内聚焦 |
| 点击六向轮盘 | 进入相应正交轴视图；再次点同方向可翻到对面 |
| 拖动轮盘 | 退出轴视图，回到一般视图 |
| 左键模型 / 空白处 | 单选 / 清空选取 |
| 左键拖框 | 框选；`Shift` 追加，`Ctrl` 从现有选取移除 |
| `Ctrl+A` | 在主视图或场景层级全选可用元素 |

场景层级与主视图共用对象选取。列表可以多选、搜索、拖动排序与拖入组；拖动途中可使用滚轮，或靠近列表边缘自动滚动。右键对象或列表项可使用相同的对象操作菜单。

设置中的「独立 UV 编辑模式」默认关闭，UV 工具并入编辑模式；开启后才出现独立 UV 模式。「Blockbench 风格操作」默认关闭；开启后，在建模视图中左键拖动旋转、右键拖动平移，只有 `Shift` + 左键拖动才会框选。左键原地点击仍可单选，右键原地点击才会弹出菜单。绘画模式保留左键作画；右键点击空白背景可打开视图菜单，但不会显示粘贴和原位复制两项。

首次使用主视图时，若尚未按过中键就用左键或右键拖动，界面会提示可以在设置中启用 Blockbench 风格操作。提示只显示一次。

## 3. 建模与变换

场景层级上方可新增 Cube、组、Locator 和 Shape。新 Cube 是底部落在水平面上的 2×2×2 立方体；在组内新增的元素会以组枢轴为初始参考。Shape 建立菜单包含柱体、多面体和 Bezier 类型。

| 快捷键 | 工具 |
| --- | --- |
| `1` | 移动 |
| `2` | 缩放 |
| `3` | 旋转 |
| `4` | 移动枢轴 |
| `5` | 顶点捕捉 |
| `6` | 刀具 |
| `7` | 面选择 |

- 手柄只接受左键；中键保留给摄像机。轴、平面和中心手柄分别执行相应维度的操作。
- 移动与旋转可选自身、父级或全局坐标；多选可在统一与分别执行间切换。枢轴移动会补偿对象参数，不改变可见几何。「枢轴居中」位于对象属性的枢轴 X/Y/Z 数值框后，多选时将所有枢轴移到整体几何中心。
- Cube、组和 Shape 的属性栏提供「应用位移／旋转」与各自的「还原」。应用后对应数值归零，后续变换从新起点累加；还原会把当前实际变换重新显示在数值栏，操作前后模型外观均不变。组的位置栏与枢轴栏分开：移动组会带着子项一起移动，改枢轴则补偿子项以保持外观。导出时写入最终姿态，不携带编辑器的归零记录。
- 旋转时按住 `Alt` 可暂时显示选中对象顶点；点击顶点可把枢轴移到该处。顶点捕捉可选交点提示，直角菱形交点只能作目标点。
- `Ctrl+Z` 撤销、`Ctrl+Shift+Z` 重做；文字输入框聚焦时，`Ctrl+Z` 优先撤销文字而非整个项目。
- `←` 和 `→` 按当前模式的工具栏顺序循环切换工具。建模时，`C` 新建方块，`S` 在鼠标位置打开新建 Shape 菜单。
- 每个项目会分别记住各模式最后选中的工具。移动、旋转和移动枢轴的坐标系分别保存，默认都是自身。合并停靠面板会记住选中的卡片。
- `Ctrl+C` 复制、`Ctrl+X` 剪切、`Ctrl+V` 粘贴、`Ctrl+D` 原位复制。这些操作会依当前焦点作用于可操作的元素或贴图。

## 4. UV 与纹理模板

1. 在左侧贴图列表建立或导入贴图，再将列表中的贴图拖到模型面上。若同时选中多个元素，会对其相同方向的面指派贴图；换贴图不会清除原有 UV 或平铺参数。
2. 在贴图视图中选取面与 UV 框。`Shift` 框选追加、`Ctrl` 框选移除；拖动框或边缘调整 UV。贴图视图的 `Ctrl` + 滚轮缩放，普通滚轮纵向滚动，`Shift` + 滚轮横向滚动，中键拖动平移。
3. 贴图视图聚焦时，`R` 聚焦选中 UV，`Shift+R` 重置贴图视图。UV 可以保留在贴图范围外以兼容特殊数据，但普通拖动不会主动把它推出去。
4. 「新建贴图 → 纹理模板」会依当前 Cube 面重新排布 UV。可选仅处理选中项、清理零面积面、箱型 UV、尺寸对齐、间隔与「不共用 UV」。后者每次打开默认勾选；取消后，相同来源和旧 UV 的面可以复用新位置，即使它们属于不同 Cube。
5. 「保留图层结构」默认开启：每张来源贴图的各图层会按新 UV 分别重排，组、可见性、混合模式与遮罩关联保留。多来源贴图各成一组；未贴图的面放在模板底图。关闭此选项则输出单张合成图。箱型 UV 默认关闭，只有格式要求箱型时强制使用。

贴图视图下方四个数值栏统一显示 X／Y 起点、宽度 W 和高度 H。普通 UV 调整起点会平移整个矩形，调整宽高会保留已有镜像方向。多选数值不一致时显示 `-`。

在图层面板顶部切换贴图模式，模式栏与新建栏不会随列表滚走。「平铺」模式下，四个数值表示 X／Y 起始偏移和整个面的像素宽／高，原贴图完整循环。例如原贴图宽 16px，面宽 W 设为 32px，就横向重复两次。这些参数与普通 UV 分开保存，切换回「默认」即可继续编辑原 UV。

启用 UV 预览的「选面后聚焦 UV」后，点击面会自动切换到该面使用的贴图并聚焦，不必先从贴图列表手动选择。

在平铺面上绘制直线、矩形或椭圆时，图形按完整的面内位置确定，再循环写入原贴图。屏幕空间绘画也按实际覆盖范围写入，笔画粗细不会因平铺而缩小。

「手翻书」是独立开关，普通和平铺贴图都可勾选。点击图层新建栏旁的齿轮，子窗口最右侧是帧元素列表：用「＋ 帧」新增，拖动整行排序，右键可复制、粘贴、剪切、原地复制或删除；焦点在帧列表时也可用 `Ctrl+C/V/X/D` 和 `Delete`。这些操作支持撤销、重做。帧不支持分组和关闭显示。

帧列表仅在开启手翻书时显示，窗口向右增加列表和约半个图层列表宽度的连线区，原编辑区不被压缩；屏幕不足时可横向滚动。由两侧圆点建立多对多连接，列表右上圆点代表全部图层，越界图层圆点吸附列表右边框。右键曲线断开；最后点击帧或图层会高亮它的连线。每帧只合成关联内容，左侧加粗边缘标记有效成员；关联组的子项可在子窗口内设置该帧专属显隐。绘画只能使用当前帧的有效普通图层，每帧记住上次选择，首次默认第一个可编辑图层。主窗口底部进度条支持拖动与点击逐帧刻线跳转，头部可设置 FPS 和帧渐变。各贴图独立播放，仅播放／暂停按钮切换状态，其他操作与失焦不会暂停；进度条随手翻书和帧的存在自动显示，不另设开关。导入 PNG 时检查同目录的 `贴图名.png.mcmeta`，拆出平级图层并关联帧，保留顺序、停留时间与渐变。关闭手翻书恢复原全局显隐，保留帧配置；原始像素、尺寸与 UV 不变。

取色器默认跳过全透明像素，在三维中继续寻找后面的面。按住 `Ctrl` 取当前帧的最终合成颜色，包含帧渐变、叠色和蒙版，不包含灯光或阴影；可与 `Alt` 临时取色叠加。

### 导出平铺与手翻书贴图

Java 方块／物品可导入、导出原生模型 `.json`；基岩版实体、方块与 GeckoLib 几何使用原生 geometry JSON。文件有多个几何模型时可选择一个；没有类型索引的基岩几何会询问按实体还是方块导入。模组版实体提供 Java 模型层导出，采用 Minecraft 1.17+ Mojang 映射的 `createBodyLayer()` 接口。仅 CubeBricks 导出且未经修改的 Java 文件可导回，修改代码或还原信息后会拒绝导入。

选择原生 JSON／Java 导出时，先逐张保存烘焙后的 PNG 及所需的 `.png.mcmeta`，最后才询问模型文件位置；取消任何一步都不会继续导出模型。Java JSON 使用命名空间资源路径；保存到资源包的 `assets/<命名空间>/textures/` 下可自动推断。模型旁的 `<模型文件名>.cbtextures.json` 保存实际相对路径和材质关联，导回时自动读取；基岩几何本身不包含贴图路径。移动交换文件时请一起保留图片与该索引，投入游戏时仍按资源包目录和材质配置安排文件。

贴图列表右键提供「保存贴图」和「贴图另存为」。新建、复制或修改后未保存的贴图右侧显示保存图标，也可直接点击；单纯导入且未修改或保存后的贴图不显示图标。保存输出完整合成图，手翻书输出完整帧条及配置；图层的可编辑结构仍保存在 `.cbmodel` 工程中。

选择 `.bbmodel` 时会在现有的 Shape／修改器几何烘焙之后处理贴图，不改变当前工程、图层或播放位置。每个动画按帧列表顺序生成纵向 PNG 帧条；导出耗时较长时显示进度。

- **单贴图格式**（例如基岩版实体、Java 模组实体）：全部贴图合并到一张图集。动画总帧数取各动画帧数的最小公倍数，逐帧循环填入各自内容；静态贴图在每帧保持不变。FPS 取动画贴图的平均值，导出帧渐变关闭。只有一张动画贴图时也遵守此规则。
- **多贴图格式**（例如 Java 方块／物品）：普通静态贴图保持独立，各动画分别烘焙并保留自己的速率、帧停留时间和帧渐变设置。
- **平铺**：按实际面的偏移及宽高生成重复纹理，同一源贴图的面共用重复平面；整周期偏移和可覆盖的区域重叠引用，不给每个面复制一张图片。渲染用的 1024px 缓存上限不会裁掉导出内容。只允许箱型 UV 的格式则将结果烘焙到固定箱型展开中，相同展开复用区域。

`.cbmodel` 仍保存可编辑的贴图、图层、帧关联和平铺参数。需要继续编辑时，请另外保留工程文件。

### 导出平铺与手翻书贴图

选择 `.bbmodel` 时会在现有的 Shape／修改器几何烘焙之后处理贴图，不改变当前工程、图层或播放位置。每个动画按帧列表顺序生成纵向 PNG 帧条；导出耗时较长时显示进度。

- **单贴图格式**（例如基岩版实体、Java 模组实体）：全部贴图合并到一张图集。动画总帧数取各动画帧数的最小公倍数，逐帧循环填入各自内容；静态贴图在每帧保持不变。FPS 取动画贴图的平均值，导出帧渐变关闭。只有一张动画贴图时也遵守此规则。
- **多贴图格式**（例如 Java 方块／物品）：普通静态贴图保持独立，各动画分别烘焙并保留自己的速率、帧停留时间和帧渐变设置。
- **平铺**：按实际面的偏移及宽高生成重复纹理，同一源贴图的面共用重复平面；整周期偏移和可覆盖的区域重叠引用，不给每个面复制一张图片。渲染用的 1024px 缓存上限不会裁掉导出内容。只允许箱型 UV 的格式则将结果烘焙到固定箱型展开中，相同展开复用区域。

`.cbmodel` 仍保存可编辑的贴图、图层、帧关联和平铺参数。需要继续编辑时，请另外保留工程文件。

## 5. 绘画

在顶部切到「绘画」。画笔、图形绘制、油漆桶、渐变、取色器与选区位于绘画工具栏；图形工具和选区工具可在工具内切换子模式。常用快捷键：`B` 画笔、`L` 直线、`M` 矩形、`O` 椭圆、`G` 油漆桶、`J` 渐变、`I` 取色器。按住 `Alt` 可临时取色，松开返回原工具；当前颜色对应选中色卡时，也可按住 `Alt` 滚轮切换色卡颜色或渐变位置。

- 二维贴图与三维模型面都可绘画。画笔可以从三维空白处起笔、跨面连续落色；未指定贴图的面不会被自动绑定当前贴图，需先指派。
- 画笔可选尺寸、方形／圆形笔尖、AA、透明度和笔刷深度。图形绘制可选填充，油漆桶可沿一次拖动处理多个面或位置。
- 在三维主视图按住 `Ctrl` 使用屏幕空间绘画：画笔、直线、矩形、椭圆、油漆桶和渐变都按当前画面投射到可见面，擦除模式同样适用。屏幕空间的虚拟像素高度可在「设置 → 视图」调整，宽度随窗口比例变化；松开 `Ctrl` 后下一笔恢复普通绘画。
- 面渐变与体渐变以两点决定方向，覆盖完整目标；可用两个色槽或当前色卡。色卡可使用离散色、连续渐变或三维色彩空间曲线。
- 选区有矩形、涂抹、自由圈选。`Shift` 追加，`Ctrl` 擦除。选区生效时，绘画限于选区内。拖动选区会提起像素并清除遮罩，单击空白处放置，撤销键可取消尚未放置的变换。沿虚线框拖动旋转手柄时，默认吸附 90°，`Shift` 自由旋转，`Ctrl` 吸附 15°。非直角旋转默认最近邻，也可切换到平滑采样。缩放时 `Shift` 保持拖动前比例，`Ctrl` 恢复提起时的比例。三维手柄随操作面投影，像素裁切在起始面内。开启选区对称可同时变换对应的面。
- 在主视图或贴图视图右键选区可复制、原地复制或粘贴。原地复制和粘贴会先放置当前浮动像素，再提起新的像素。浮动像素还可删除或移到原图层正上方的新图层。
- 贴图栏聚焦且有选区或浮动像素时，`Ctrl+X / C / V / D` 分别剪切、复制、粘贴和原地复制像素。剪切后可在贴图视图直接粘贴。绘画模式下，`Delete` 可删除浮动像素，场景中的模型元素受保护。
- 在贴图视图使用油漆桶时，面和元素模式填充当前图层；同色和连续同色模式仍可限定在单面内。
- 绘画对称须先在元素或组的「操作器」页挂载，再于主视图编辑对称轴。它只复制绘画输入，不产生新模型。绘画模式仍可从场景层级切换可见性与锁定，但不能修改几何。

## 6. 图层、色卡和窗口

图层列表可新增图片层或组、拖动排序、折叠与切换可见性；新建栏在滚动时保持可见。右键图层可向下合并或删除，合并会把上层的混合结果写入下层像素。列表旁的齿轮打开图层编辑子窗口，在其中也可使用图层右键菜单，并编辑名称、透明度、混合模式、色阶映射和蒙版来源。切换当前图层不会清空其他图层；绘画预览只重算落色区域，收笔后保存完整贴图。

右键图层还可复制、粘贴与就地复制；图层列表获得焦点时分别支持 `Ctrl+C`、`Ctrl+V` 和 `Ctrl+D`。复制组会保留子层及内部蒙版关联，副本使用独立编号；选中组时粘贴到组内，就地复制则与原组同级。手翻书下粘贴的内容关联当前帧。「二值化透明度」只修改像素 alpha：0 保持为 0，其余改为 255，RGB 保持不变；对组操作时处理组内各图片层，保留组结构、混合模式和图层透明度设置。粘贴、就地复制及二值化均可撤销。

色卡可新增、选色、排序、删除，右键可改名，并把当前选中的单张色卡导出为 `.cbcmap`；导入会追加而非覆盖。新色卡默认属于当前项目，会随 `.cbmodel` 一起保存；可用色卡上的「项目／全局」按钮或右键菜单改为全局共用。导出 `.cbmodel` 时，图层实际引用的全局色卡也会嵌入文件，接收方可继续编辑色阶映射。色卡列表可缩略显示。视图左、右、底部的停靠窗口可拖出、靠近边缘吸附或拖到另一个窗口的标题上合并；折叠与尺寸在每个停靠位置管理。
