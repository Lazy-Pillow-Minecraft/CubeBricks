# CubeBricks 0.1.3-beta

[English](RELEASE_0.1.3-beta.en.md) · [返回 README](../README.md) · [上一版说明](RELEASE_0.1.2-beta.md)

## 本版改进

- **主视图性能：** 减少视角拖动中的重复计算和界面更新，手柄 SVG 复用已有节点；补充 CPU、GPU、输入与主线程分段记录，便于继续定位偶发停顿。
- **后台记录与撤销：** 项目日志的快照、读写、历史切换及归档移至独立工作线程；优化最近历史的内存恢复和受影响模型的局部刷新，保留原有操作顺序、校验与崩溃恢复规则。
- **贴图恢复：** 修复部分图层状态和不同 PNG 编码导致的还原校验失败；几何撤销保留现有贴图，贴图恢复时保持已有图集，减少空白和闪烁。
- **绘画与图层：** 改善二维／三维笔画的实时反馈与多图层局部合成；支持按住 Ctrl 的屏幕空间绘画，并补强面边缘覆盖。图层新增向下合并与删除菜单，新建栏固定显示；色卡可右键改名。
- **纹理模板：** 修正勾选「不共用 UV」时仍可能复用位置的问题；该选项默认开启，取消后仍可跨 Cube 复用符合条件的面。
- **代码与文档：** 梳理几何工具的依赖边界，检查脚本验证模块循环引用；同步简体中文与英文操作说明。

## 验证范围

源码及模块图检查、62 项记录／撤销测试、模型、模块和渲染测试通过；安装包内容与隔离启动检查通过。自动视角基准未复现固定半秒停顿，但内部注入输入不覆盖完整的物理鼠标链路，不能据此保证所有设备上的周期停顿均已消除。

## 上传备注

CubeBricks 0.1.3-beta 主要改善主视图、绘画和撤销的流畅度：项目记录移至独立工作线程，手柄改为复用节点，减少背景保存和界面重建对操作的影响。修复部分贴图还原校验失败及撤销闪烁，改善笔画实时反馈和多图层局部合成，补强 Ctrl 屏幕空间绘画与面边缘覆盖。新增图层向下合并／删除、固定新建栏和色卡右键改名，并修正纹理模板「不共用 UV」的分配问题。同步更新中英文文档。

Windows 安装包：`CubeBricks-v0.1.3-beta-win-x64-setup.exe`。
