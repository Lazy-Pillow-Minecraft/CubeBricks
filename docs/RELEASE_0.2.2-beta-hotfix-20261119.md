# CubeBricks 0.2.2-beta-hotfix-20261119

本次差异以 `0.2.2-beta-hotfix-20261118` 安装包内的实际源码为基准。

安装包：`CubeBricks-v0.2.2-beta-hotfix-20261119-win-x64-setup.exe`。

## 编辑工具

- 新增工具箱，位于面选择之后，包含等比缩放、翻转、90°旋转和居中。
- 等比缩放提供整体包络框尺寸吸附、每个元素尺寸单独吸附和不吸附。长宽高分别吸附，支持拖动中实时切换 Shift、Ctrl、Ctrl+Shift 精度；每次完整拖动只记一步撤销。
- 翻转提供全局原点、枢轴中心两组 XYZ 操作；90°旋转提供两种中心下 XYZ 正负方向，共 12 个按钮；居中可按几何中心或枢轴执行单轴或三轴操作。
- 保留组层级和 Shape 参数；修正翻转后的曲线节点、细分编辑及 UV 修改的坐标换算。
- 修改器结果可直接选中并映射编辑源元素，保留生成部分的反色选框；操作手柄跟随选中的生成实例，移动、缩放、旋转和枢轴操作换算回源元素，顶点捕捉也支持对应实例。
- 刀具由起点确定切割对象与位置，第二次点击只决定方向，可落在其他面、其他元素或背景上，正交与透视使用同一套平面计算。

## Java 格式与 UV

- Java 方块／物品新增「取消区域限制」项目选项；导入原始坐标已超出范围的 bbmodel 时自动关闭该限制，并在保存、导出和重新导入时保留设置。
- 修正 90°旋转对已有斜角 Cube 的处理，将完整直角部分换算到几何尺寸和面 UV，必要时调整剩余旋转的轴；修正旋转缩放补偿在姿态换算时造成的尺寸变化，保留负尺寸与隐藏面。
- 贴图尺寸使用「拉伸」时同步拉伸已分配 UV，并按实际像素格点吸附；兼容高分辨率贴图、箱型 UV 与 Shape 细分覆写，像素和 UV 一同撤销、重做。

## 布局与界面

- 修复停靠卡片布局重启后丢失或恢复顺序错误的问题，独立保存布局，并保留尺寸、位置、折叠、合并和选中分页。
- 修复默认色卡拖动后排序不生效；渐变色值节点的圆环与竖线使用主题色，并消除二者之间的缝隙；移除多余的色卡统计提示。
- 统一新建菜单与场景层级的元素图标，更新提供的翻转、旋转、居中及工具箱图标。
- 工具箱轴向按钮使用红绿蓝区分 XYZ；UV 预览翻转按钮使用普通主题样式，不再按轴染色。提亮按钮，枢轴居中改为正方形，修复工具箱下拉菜单多余的实心方块。
- 移除主视图背景及元素右键菜单的前置装饰图标，补齐相关翻译与中英文操作说明。

## 验证

通过源码及依赖检查、模型与导出回归、渲染回归、配置和布局测试、修改器结果编辑测试，以及工具箱和三个 Java 版本类别的 12 种旋转组合验证。另完成独立资料目录中的启动与界面样式检查。
